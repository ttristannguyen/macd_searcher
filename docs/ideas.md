# Ideas

This file holds the open hypotheses that we did not test yet. Keep each idea short.

- Write the mechanism and the expected sign before you test the idea.
- When you test an idea, write the result in [research_log.md](research_log.md).
  Then remove the idea from this file.
- If the result needs live confirmation, add a `Check` to `rules.WATCHLIST`.

Use this format for each idea:

```
## <name> (<date>)
Mechanism: <why it can work>
Test: <what to measure, and the sign that confirms it>
Source: <the doc or the log entry that gave the idea>
```
